## Reporting a Vulnerability

Security and user privacy are foundational values of **Veltra Track**.

Because Veltra Track operates on a **100% local-first model** (client-side execution, data stored in local browser storage, and no centralized databases), risks relating to remote server vulnerabilities are fundamentally minimized.

However, if you discover any potential security vulnerability, client-side injection issue, or data privacy bug:

1. **Please do NOT open a public GitHub issue.**
2. Send an email with reproduction details to [teja1616150@gmail.com](mailto:teja1616150@gmail.com).
3. We will acknowledge receipt within 48 hours and work with you to test and deploy a fix promptly.

Thank you for helping keep the open-source community secure!
